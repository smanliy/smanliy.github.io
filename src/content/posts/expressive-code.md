# 把代码也写得温柔一点

以后你在这里写技术内容时，也可以不用太硬。

代码块负责准确，  
文字负责安抚读者的呼吸。

比如：

```ts
export function sayHello(name: string) {
  return `你好，${name}。今天也慢慢来。`
}
```

这样一来，技术文章也会像这个博客一样，  
有一点克制，但不冷。
