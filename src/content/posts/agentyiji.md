# Agent记忆分层
## 感知记忆（Sensory Memory）
生命周期：最短，单次输入
内容：本次调用原始输入，用户消息、上传文档、图片等原始信息
特点：只做入口接收，本次调用处理完就直接消失，不会保存。类比刚听到一句话，几秒就忘掉。

## 短期记忆（Short-term Memory）
载体：上下文窗口 context window 的 messages 列表
内容：当前任务 / 对话全程状态：用户提问、模型输出、工具返回结果
特点：任务进行中可见；任务结束 / 对话关闭就清空；有 token 上限，空间有限，像工作台。

## 长期记忆（Long-term Memory）
载体：外部存储（向量库、KV 库、关系型数据库），任务结束后依然保留，需要检索召回
分为 3 个子类：
情节记忆 Episodic：完整历史任务经历（时间、场景、过程、结果）。遇到相似任务可以参考历史做法，避免重复踩坑。
语义记忆 Semantic：多次经历提炼出的通用知识、规律。抽象结论，信息密度高，检索更容易命中。
程序记忆 Procedural：操作流程 / SOP，“怎么做一件事”。遇到同类任务直接套用流程，不用从头推理，速度快。
工程上三者经常混合使用。

## 实体记忆（Entity Memory）
比长期记忆更精炼，抽取对话里关键实体、事实，保存成结构化字段
例子：用户偏好 Python、项目截止日期、预算。类似病历，只存结构化结论，不存原始对话全文。
优点：信息密度高、查询快，不受原始表达方式影响。
